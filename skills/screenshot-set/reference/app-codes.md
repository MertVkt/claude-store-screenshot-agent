# App codes

Each app gets a fixed three-letter code. The code is used in folder names, Figma page names and brand files,
so pick it once and keep it. It does not have to come from the app name; always look it up here.

| App | Code |
|---|---|
| Demo Photo | `DMO` |
| Lumen | `LMN` |

Add your own apps to this table. For an app that is not listed, ask the user for the code; do not invent one.
When a new code is given, remind the user to add it here so it persists across plugin updates.

Set folder `<CODE>SS<nn>` (e.g. `LMNSS01`), Figma page `<CODE> SS<nn>` (e.g. `LMN SS01`), brand file
`<App>/_brand/<CODE>.tokens.json`.
